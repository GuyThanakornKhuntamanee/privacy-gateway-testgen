| Formal skill A/B benchmark (with vs. without skill) | Not run | Two skill-guided runs were executed, but there was no baseline comparison. The repository's automated tests and quality gates provide the quantitative evidence for this release; agent-behavior timing/token benchmarks remain future work. |
| External detector validation | Not run | The tool produces ground truth; it does not claim accuracy against a particular third-party detector. Plug in your gateway and use the dataset to measure it. |
| Performance/latency claims | Not run | Out of scope; the generator is a batch tool. |

## Release decision

The repository checks, security scans and quality gates pass on this checkout.
That supports a **v0.3.1 public testing release** with the additive schema 2.1
file-aware generator and the v2.1.1 correctness hardening. It does not certify
any downstream privacy gateway, and it is not a claim of legal or PCI DSS
compliance. Review `docs/evaluation-report.md` and `reports/v2/evaluation.md`
before publishing.
